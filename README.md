# Brew & Spice CRM

Brew & Spice CRM is a simple coffee shop management system made using Django, SQLite3, HTML, CSS, and JavaScript.

This project was created to manage customers, orders, footfall tracking, inventory, and basic analytics for a coffee shop.

---

## Features

* Customer management
* Order management
* Footfall tracking
* Peak hour analytics
* Inventory management
* Dashboard with charts
* Staff and admin login
* Product management

---

## Tech Stack

* Python
* Django
* SQLite3
* HTML
* CSS
* JavaScript
* Chart.js

## Project Setup

### 1. Clone the project

```bash
git clone <your-repository-link>
cd brew_and_spice
```

### 2. Create virtual environment

```bash
python -m venv venv
```

### 3. Activate virtual environment

Windows:

```bash
venv\Scripts\activate
```

### 4. Install requirements

```bash
pip install -r requirements.txt
```

### 5. Run migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. Run server

```bash
python manage.py runserver
```

Open browser:

```text
http://127.0.0.1:8000/
```
